## Bugs found and fixed (verification caught all of these)

1. **`.sec-head-row > *` specificity trap** — that rule (later in source, same
   specificity as `.sec-index`) flipped the ghost numeral from `absolute` to
   `relative`, which would have dropped a giant numeral into the flow above
   every row heading. Now scoped to `> h2, > .sec-more`.
2. **`records.css` cascade order** — my premium `.search` rule sat *before* the
   base `.search` rule, so `background: #fff` won and the hairline never
   rendered. Moved below the base block. (The exact failure Hussein predicted.)
3. **Contrast under the grain** — `--ink-3` #55677E and `--sky-600` #2E6A9E fell
   to 4.33 / 4.30 worst case once the 5 % grain overlay was modelled.
   Retuned to **#4E6076** and **#2A6291**. `.tl-index` (was .75 opacity) and
   `.chain-num` (was .85) were 3.6 / 4.2 — now full strength. `.hero-scroll`
   opacity .8 → 1. Audit tool: `tools/contrast-audit.js` (reads the live
   tokens out of site.css, 24 pairs, all ≥ 4.5 clean **and** under grain).
4. **Tap targets** — `.lang-btn` 34 → 40 px, `.sec-more` 28 → 40, `.stat-link`
   26 → 40, footer nav links → 40.
5. **Reveal threshold** — `.12`/`.1` left a visible sliver at the bottom of the
   viewport un-revealed; now `threshold: .01`, `rootMargin: 0 0 -5% 0`.
6. **`.chain li` pill leftovers** — `white-space: nowrap` survived; now `normal`.
7. **Switcher had no accessible name** — buttons read only `ع / EN / RU`.
   Added `lang.name.ar/en/ru` keys + `data-i18n-aria`; labels localize:
   ar → العربية/الإنجليزية/الروسية · en → Arabic/English/Russian ·
   ru → Арабский/Английский/Русский, with `aria-pressed` following the active
   language and the visible text unchanged (approved exception).
8. Stale `rgba(46,106,158,…)` literals retuned to the new sky-600 rgb(42,98,145)
   in `--pane-line`, the stage corner ticks and the search focus ring.

## Environment learnings (important for next time)

- **The desktop browser window is hidden → Chrome produces no animation frames
  (`document.timeline.currentTime` never advances).** IntersectionObserver
  callbacks and rAF are therefore silent, smooth scrolling never completes, and
  computed styles can be stale. Any scroll-driven check in the harness is a
  false alarm there: the harness now samples the timeline and skips IO checks
  with a `framesOff` note instead of reporting them as failures.
- **`localStorage['site-lang']` beats `?lang=`** (i18n `getLang()`: saved →
  param → default `ar`), and only a click on a switcher button ever writes it.
  The harness must seed `site-lang` per case or every case renders the last
  language used.
- PowerShell prints Arabic as `?????` — console encoding only, files are fine
  (verified with Node: no U+FFFD anywhere).
